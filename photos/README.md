# Photo inbox

Drop every photo for Vuwani in this folder. Any names, any sizes, phone photos are fine.

Claude picks from here, resizes and compresses the chosen ones into `assets/img/`, and writes the copy around them. Nothing in this folder appears on the website by itself.

Helpful but optional: name a file after what's in it, for example `grandpa-1978-soweto.jpg` or `lapel-closeup.jpg`.
